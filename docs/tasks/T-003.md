# T-003 源码非正式说明字符串清理

状态：待开始 · 阶段：阶段间治理 · 负责：外部 worker · 分支：`task/T-003-bare-doc-strings` · 产品基线：`7355588`

## 目标

清理产品源码中全部 7 处 PEP 224 风格的非正式说明字符串：把仍有维护价值的说明改写为贴近目标符号的
简洁英文 `#` 注释，删除原来的裸字符串表达式，使全仓不再存在“形似 docstring、实际参与 AST”的说明
节点。除这 7 个明确节点外，不改变任何可执行 AST、产品行为或公共契约。

## 契约与约束

- 只处理以下 7 个裸字符串表达式，不自行扩展范围：
  1. `context_builder.py`：`MAX_AGENTS_FILE_BYTES` 后的说明；
  2. `events.py`：`EngineEvent` 后的说明；
  3. `providers/base.py`：`ProviderEvent` 后的说明；
  4. `session_contracts.py`：`CURRENT_SESSION_FORMAT_VERSION` 后的说明；
  5. `session_contracts.py`：`SessionEntry` 后的说明；
  6. `session_contracts.py`：`SessionRecord` 后的说明；
  7. `tui/main_buffer/interactions.py`：`InteractionOutcome.action` 后的说明。
- 每条有价值的说明都改成位于目标常量、类型别名或字段正上方的简洁英文 `#` 注释；不得改成新的普通
  字符串、运行时元数据或自定义描述符，也不得给现有类型增加新行为。
- 保持原说明的真实语义，不扩写施工背景；`InteractionOutcome.action` 必须继续准确说明
  `none`、`response`、`cancel` 三种稳定值。
- 不得修改目标符号本身、类型别名成员、常量值、导入、类型注解、公共导出、运行时文本、控制流或数据
  结构；不补测试、不重构邻近代码。
- 本任务允许且只允许删除这 7 个 `Expr(Constant[str])` AST 节点。新增的 `#` 注释不进入 AST；除此之外
  的 AST 差异一律视为越界。
- 不更新冻结中的 `docs/module_map.md`，不开始测试资产精简或源码架构重构。
