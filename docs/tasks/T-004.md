   （纯契约、组件行为、跨层生命周期、CLI/分发、平台/物理行为）、对应产品入口、独有高价值边界和

   当前等价保护的文件与测试名，或对应产品行为已经退役的源码/Git 证据。无法完成一一映射的项目只能
   标为“待进一步调查”，不能进入删除批次。
5. **审查阶段号资产**：逐一检查所有 `test_p*_*.py`；判断它们应迁入哪个行为命名模块、是否与现有模块
   重复，以及哪些场景是仍需保留的跨层生命周期证据。阶段号本身不是删除依据。
6. **审查共享测试装配**：定位重复的 Provider、App、事件收集与终端 harness，比较其构造参数、状态和
   断言差异；只建议抽取真正稳定且窄小的公共协议，不设计隐藏大量默认行为的万能 `conftest.py`。
7. **审查等待与慢边界**：列出固定 `sleep`、真实墙钟等待、子进程、安装构建和平台相关测试，区分可由
   Event/队列/状态变化替换的猜测性等待，与确实验证时间或平台行为而必须保留的等待。
8. **形成实施批次**：按依赖关系拆成可独立验收的小批任务。每批必须写明目标、精确候选文件、保护的

   的重复资产，不在单批中混入产品重构。

#### 共享装配比较

- `ScriptedProvider` 并非一种协议：App 版本支持异常脚本；Engine 版本不负责 `aclose`；P5-10G 会复用最后
  script；Screen 版本有 `started/release` 阻塞状态；CLI 版本记录 `aclose_calls`。不能做万能 Provider。
- 可消除的完全相同实现只有局部族：P4-08/P4-13/P4-14 的 Provider；P5-09/current TUI CLI 的 Provider
  与 dependency builder；P3/P4-08/P4-09/P4-13/P5-09 的 Recorder。优先通过把测试迁入同一行为模块来

#### 等待、慢速和平台边界

- `sleep(30)`/`sleep(3600)` 只位于必然被取消的 hanging fake，不产生实际 30/3600 秒等待；保留为挂起点。
  `asyncio.wait_for(..., timeout=...)` 是死锁上界，不是猜测性等待。
- 可替换的固定短等待：CLI 无文本取消 0.05 秒、P3 cancel 0.01 秒、Provider cancel 0.05 秒及旧 transport
  的 0.005/0.02/0.05 秒、TUI Ctrl-D/运行态/双 Ctrl-C 的 0.05 秒。用 provider emitted、input consumed、
  screen mode/clock 或 cleanup Event 加有界 `wait_for` 替代；`pump()` 的 0.005 秒轮询也应由状态通知逐步
  收敛，但不与测试合并批次混做。
- `test_runtime_tools.py` 四次 0.01 秒轮询 marker 可保留有界轮询或改为文件/进程启动 signal；两处普通
  bash cancel 的 0.05 秒应改为启动 Event。四次 `time.sleep(2.3)` 等待后台 `sleep 2` 后确认 marker
  不出现，真实证明 output-limit/timeout/token-cancel/task-cancel 均回收后代；在没有确定性 OS cleanup
  signal 前必须保留并单独标记为慢速平台测试。
- 子进程边界：CLI/public-import smoke、JSONL 双进程竞争、runtime bash、Windows junction 和 distribution
  的 build/venv/install。前三类是隔离或并发证据；distribution 是安装后证据，均不能由 mock 替代。
- 平台边界：Windows Git Bash discovery、Windows junction、真实 console record gap/fallback；非 Windows
  的 skip 不等于无价值。其余 HTTP 使用 MockTransport，distribution 使用 loopback server，无外网和真实 Key。

## 候选经验

<!-- 可复用的教训：现象、证据位置、建议去向 -->

- **阶段名不是失效证据**：11 个阶段号模块全部命中现行入口，且部分文件名与首次提交主题已经错位；先按
  行为迁名，再讨论重复。建议经用户确认后写入测试治理规则。
- **相同终态不等于相同取消契约**：token cancel、外部 task cancel、consumer `aclose()` 和 UI cancel
  承担不同 cleanup 责任；只能在每条入口仍有证据时合并。
- **长 sleep 数字不等于慢测试**：30/3600 秒是被取消的挂起哨兵；真正墙钟成本是四个 2.3 秒后代进程
  观测。等待审计应区分“不会走完的挂起点”“死锁上界”“猜测性短等待”“真实平台时间窗”。
- **共享 fake 以状态协议分族**：Provider、App、终端 harness 只有构造参数、状态与失败语义一致时才共享；
  通过行为模块合并自然去重，优先于全局 `conftest.py`。
