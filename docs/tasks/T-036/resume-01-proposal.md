# T-036 恢复施工方案 · 第 2 轮 · 待授权

依据：[第一轮审查](review-01.md)、[worker 报告](worker-01.md)。用户选择继续处理 Messages，不转入 C1。本文件是待确认的权限与执行方案，**尚未派发，不授权读取真实配置/凭据或发送模型请求**；T-036 当前仍为阻塞。

## 需要一次性确认的权限

批准后才允许同一个独立 worker 在既有任务 worktree 中，通过产品已有的受保护读取入口，在进程内解析已确认的 Messages 与 Completions 测试连接，做下面的隔离取证，并对证据支持的本地缺陷直接修复和回归。只使用这两条测试连接，不任意选择其他连接、模型或地址；若不能唯一确认则停止。

这会明确扩大此前“worker 不读真实凭据/不访问渠道”的权限，仅限本轮。真实 auth 文件的必要受保护读取不代表可使用其中其他凭据；不读取用户会话、其他客户端凭据或私有控制台。不修改真实配置，不把凭据复制到临时配置、代码、日志或会话。

- 新增真实模型请求最多 **5 次**；此前 3 次继续计入，相关实验累计上限从 5 调整为 **8 次**，不重置计数。
- 每请求含流消费最多 30 秒，输出预算 1024，thinking disabled，零自动重试、不跟随重定向；不请求 Responses。
- 全新隔离 HOME/配置/会话/工作区，只使用合成任务与自己新建的文件，不读取或发送项目源码、用户文件、原会话或工作区 AGENTS。
- 每组仅声明一个 read，限定精确临时文件，最多真实执行一次；两组总计最多 2 次 read。模型不得执行 write/edit/bash/ask 或其他路径的工具。此限制不妨碍 worker 使用开发终端编写和运行获准诊断、修复及离线测试。
- 真实请求/响应、认证、地址、具体模型标识、正文、参数值、工具 ID、文件内容及本地绝对路径仅留有界内存，不持久化或打印。仅输出严格白名单枚举、计数、布尔值和规范化字段路径。

## 执行与分支选择

### H：优先取得历史拒绝的具体字段（最多 3 请求）

新建隔离的真实 Completions 一次 read 往返，使用实际产品 Provider/Engine/ToolExecutor/read，最多两次请求；必须观察到真实合法调用、一次成功读取、关联结果回传及正常完成。没有实际工具事实则停止该组，不伪造、不强制 Completions 选工具、不重复尝试。

以本轮实际消息构造 Messages 历史请求，保留真实工具事实、正确关系及既定转换规则，只请求一次。出站前在内存核对角色、块、input 对象、ID 关联和定义；对齐可对齐的参数并报告其余差异。只使用单 read 的最小历史，不宣称精确重现旧五工具场景或用户原会话。

若为 HTTP 400，观察器读取有界错误体，仅提取严格允许的错误类别及字段路径：只接受已知协议字段和合法路径语法，规范化数字下标，不记录原始字符串或未知值。没有可安全提取的字段时记为“未知”。正常终态、HTTP 拒绝和解析失败分别报告，不因模拟 400 就认定根因。

### 若 H 确认了可修复的本地缺陷

把本轮安全结构特征转为合成失败回归，在原卡代码写入范围内修复并完成离线验证；不得照抄原始响应、用户数据或秘密。允许在计数闸门内额外发送 **1 次** Messages 请求，以本轮新建的实际历史验证补丁；这不是对原请求的盲目重试，必须先有明确反例和代码修复，零自动重试。

此分支最多新增 4 次请求，结束后停止真实诊断，不再启动 A3；余量不要求用完。需要公共契约、权限、持久化、依赖或渠道特有策略变化时，仍须按 code_spec §1.3 交回，不能自行改既定设计。

### 若 H 未确认本地根因，执行 A3（最多 2 请求）

仅剩余额度足够完整两步时才启动。使用同一轮冻结的 Messages 连接，新建另一隔离用例，采用独立手写协议请求，第一步只增加 `tool_choice: {"type": "tool", "name": "read"}`。这是**支持状态未知时的兼容性探测**，不宣称事先确认目标支持，也不改变产品默认策略。

若收到唯一合法 read，真实执行该组获准文件读取，并在第二请求带实际调用/结果，省略 tool_choice 恢复 auto。首答拒绝、无调用或异常调用均停止该组，不再追问或换参数重发。强制成功仅证明本轮显式选择链路可用，不单独证明旧 auto 无调用根因；拒绝也不自动等于模型完全不支持工具。

H + A3 最多新增 3 + 2 = 5 次。安全/预算守卫触发、观察器故障或连接身份不明时整体停止；已知诊断场景的 HTTP 拒绝结束该组，允许按上述分支进入尚未执行的另一组，不能借此重试同组或超预算。
