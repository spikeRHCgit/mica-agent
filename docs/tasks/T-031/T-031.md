## 具体实现目标

- 普通对话、纯思考和客户端工具往返正常完成，正文与思考分开，签名和密文不显示。
- 同源兼容续接按原顺序回传，工具调用和真实结果一一关联；无法合法转换的历史安全拒绝，不补造结果或执行历史工具。
- 截断、拒绝、服务端暂停、流内错误、断流和取消保留真实状态，不冒充成功，不执行不完整工具。
- 未知专属内容和无法忠实表示的输出降级；续接累计有上限，错误与资源收口安全。

## 具体实现方案（2026-10-14 用户审查通过）

### 请求与思考配置

- 新模块定义 `AnthropicMessagesProvider`，直接导入，使用 httpx，不新增 SDK 或依赖。构造参数沿用既有风格：api_key、base_url（默认 `https://api.anthropic.com/v1`），及 timeout、max_retries、retry_backoff、sleep、transport、thinking_level_map；默认 30 秒超时、1 次重试、1 秒退避。
- 模块自己的 resolve_endpoint：完整 `/messages` 端点去尾斜杠，否则追加 `/messages`，不重复追加；移除 URL userinfo，避免 httpx 引入 Basic 鉴权。凭据仅进入 `x-api-key` 头，显式发送 `anthropic-version:2023-06-01` 与 JSON Content-Type；repr 不显示凭据或 URL。
- request.api 必须为 ANTHROPIC_MESSAGES。发送 model、messages、stream=true、max_tokens（request.max_tokens 或 4096）；system 为顶层 text block 数组，按原顺序取仅位于历史开头的 system 消息。历史中途 system 用固定安全错误拒绝，不提升其他消息，不静默改变其时序。
- tools 编码 `{name,description,input_schema}`，schema 原样取 ToolSpec，不启用 strict 或服务端工具。
- 本卡非 off 使用稳定 adaptive 路径：`thinking:{type:"adaptive",display:"summarized"}` 与 `output_config:{effort:<映射值>}`；不发送 budget_tokens、beta 或绑定丢弃选项。默认映射仅 low/medium/high/xhigh/max 同名；minimal 无默认映射，固定安全错误结束。非空显式映射优先（请求映射优先于构造映射），映射值仅接受官方 effort 枚举；缺失或空映射用默认。
- off 显式发送 `thinking:{type:"disabled"}`，不发送 effort；不能用省略 thinking 声称关闭默认 adaptive。模型不支持 disabled、adaptive 或某档 effort 时保留服务端真实失败，不猜模型名、改参数或剥离续接重试。本卡不支持旧模型 manual budget 模式；其配置能力与装配留后续步骤核对，不宣称全模型兼容。

### 历史、工具与续接

- user 编码 text block；assistant 无兼容续接时以正文 text（非空）后接 tool_use 编码；空 assistant 无调用用空正文 block 保留步骤，若渠道拒绝则保留真实错误。其他接口的思考不放入 Messages。
- 兼容条件为已知 provider_id、记录 provider/model/api 三者相同且 REPLAYABLE；无论是否兼容都消费对应 assistant 槽位。兼容时按 items 顺序还原 thinking、redacted_thinking、text 引用和 tool_call 引用；signature/data 原值，正文和参数取同一步通用消息。不得恢复不可回放记录的专属字段。
- 同一 assistant 的全部工具结果必须紧接其后，合并为一条 user 的 tool_result 数组；已有紧接的普通 user 文字可放在结果之后，不补造文字。重复结果、孤立结果、先于调用的结果或工具调用缺失结果均拒绝请求；保留通用历史，不自动执行或补造结果。此处 Messages 的严格配对要求与 Responses 可保留未完成调用不同。
- 工具 ID 若符合 `^[a-zA-Z0-9_-]+$` 则保留；否则仅在本次请求中为调用和对应结果建立确定、唯一、无碰撞的 ASCII ID 映射。先保留所有合法原 ID，再为非法 ID 分配，保证不同原 ID 不碰撞。通用历史、Finish 与续接记录的身份不改写；兼容含思考记录若需改写其关联工具 ID则固定诊断拒绝，不能修改签名绑定内容后声称原样回放。
- Message 未提供独立工具结果状态：原样传递真实 content，不通过字符串猜 is_error，也不添加假成功标记；本卡不扩充公共消息。需表达无法取得的状态时汇报，不越界改契约。
- 来源绑定是本地回放条件，不能保证服务端前缀或账号绑定仍有效。签名拒绝保留真实错误，不发送 `prefix_mismatch_behavior:"drop_block"`，不自动去签名重试。

### SSE、内容块与终态

- 正确按帧读取 SSE，支持注释、空行、event、多行 data；event 存在时与 JSON type 一致。ping 为保活。未知事件或语义内容不能默默忽略后声称可回放。
- 状态机校验唯一 message_start、block index 和生命周期、唯一工具 ID/名称、delta 与块类型匹配、block_stop 收口。重复或缺失起止、身份冲突、delta 在 stop 后、未收口块即 message_stop 等按 malformed 结束。
- text_delta 产生 TextDelta；thinking_delta 产生 ProviderReasoningDelta；signature_delta 单独累积且不显示。redacted_thinking 的 data 不显示。start 的已知完整正文/思考可发出，后续 delta 只追加，不重复；工具 start input={} 是碎片占位，input_json_delta.partial_json 按顺序累积，在 block_stop 解析完整对象。无 delta 时用 start input；非空 start input 与后续碎片有冲突时拒绝，不猜覆盖。
- JSON 参数必须为对象，非法 JSON、重复键、非有限数值和非法 Unicode 等安全拒绝；工具只在合法完整终态交回 Engine。输出块 done 不产生 Finish。
- message_delta 收集真实 stop_reason，message_stop 才收口；reason 原样使用 end_turn、stop_sequence 或 tool_use。tool_use 必须有完整客户端调用；end_turn/stop_sequence 不得夹带待执行调用造成静默丢失或执行；不一致为 malformed。
- max_tokens、model_context_window_exceeded、refusal、pause_turn 使用固定安全 ProviderErrorEvent 结束，不发 Finish，不执行工具。保留已发正文/思考，pause_turn 不伪装成本地工具循环。未知 stop_reason 固定错误。message_delta 不是终态；[DONE]、EOF、断流或只有 block_stop 均不能成功。正常终态后停止消费，只发一次终态。
- 流内 error 按明确 error.type 分类（鉴权、限流、超时、过载/临时服务端错误），未知类型为 ProviderError；诊断不带原始 message/body。HTTP 和连接错误按既有类别处理；只对输出前的连接失败/超时、临时 HTTP 错误有限重试。HTTP 建立后断流或读超时为 malformed，不重试；取消传播 CancelledError 并关闭响应，aclose 幂等。

### 续接与内存边界

- 以原块顺序生成 MessagesThinkingItem、MessagesRedactedThinkingItem、TextItem(None)、ToolCallItem（以实际契约类名为准）。正文非空恰有一个 text，正文为空无 text；多正文块无法忠实表示时整步不可回放，通用文字仍保留。
- 已知来源正常空输出/空正文且无专属内容或降级返回 None；非空可忠实回放项返回 REPLAYABLE；真实降级返回空 items 的 UNREPLAYABLE；未知来源返回 None。
- 完整 thinking 缺有效 signature、redacted 缺有效 data、未知块/语义字段、不可表示多正文等降级。已知协议包装字段不能误判；未知服务端工具不转成本地调用。签名/data 不做清洗，最终保存判定由 Engine 完整原始消息清洗负责。
- 用 continuation_size 的紧凑 JSON UTF-8 wire 字节计量（含绑定和引用项），单步超过 1 MiB 立即释放专属累计并保持 sticky UNREPLAYABLE；后续 signature/thinking delta 不重新累积专属内容，保留必要长度/散列用于一致性核对。不能保存整个原始响应副本；通用文字与工具参数沿用既有约束。
