## 调查目标与方法

### 1. 独立核对协议与当前编码

- 优先读取官方 Messages 与工具使用文档，记录准确链接、核对日期，以及与本题直接相关的字段规则；可以读取无需登录的公开文档，不得上传项目代码、任务卡或用户数据到外部诊断服务。
- 重点核对：工具名称/description/input_schema 的声明、工具选择选项及与关闭思考的关系；tool_use 的 id/name/input；tool_result 的关联、所在角色和排序；content block、空正文、输出预算、必要请求头及流的完成条件。只列影响当前实验的规则，不扩展成全协议调研。
- 官方参考入口：`https://platform.claude.com/docs/en/agents-and-tools/tool-use/overview`、`https://platform.claude.com/docs/en/build-with-claude/thinking-tool-workflows`；若入口跳转，跟随至官方目标页面。无法抓取时明确标记未核实，不把搜索摘要或既有测试样本当作官方依据，不绕过访问限制。
- 按字段建立“官方要求 / Mica 实际编码或解析位置 / 现有测试证据 / 尚待真实确认”的简短对照。没有证据的兼容性判断只列为假设。

### 2. 验证本地工具链路，不替模型做能力证明

- 在隔离 HOME/USERPROFILE、配置和会话目录中使用假 Key、合成消息、临时随机文件及模拟网络；测试初始化前完成隔离，不读取真实环境凭据或用户会话。
- 检查实际 Messages 编码发送的工具声明和 schema，不仅检查中间 ToolSpec；最小案例采用与 read 一致的单一只读工具声明，另核对应用当前五工具的实际定义是否有可疑差异。
- 用已核对格式的合成 SSE 证明：tool_use → Provider 工具事件 → Engine 调用 → 一次真实读取指定临时文件 → 带关联工具结果的下一请求 → 正常终态。只隔离网络边界，不能 fake 被检查的编码、解析、Engine 交接或 read 动作。
- 若现有测试已完整覆盖上述行为，直接运行并引用对应测试，不另建重复用例；缺少的具体断点才写入离线诊断测试。被测 Agent 的工具读取限定到新建的指定随机文件；禁止其实际执行 write/edit/bash/ask 等其他工具，禁止任何真实模型或渠道网络请求。此限制不禁止 worker 使用终端运行获准的离线检查。
- 构造的 SSE 仅证明本地可处理这种响应，不证明真实渠道会生成 tool_use。不要用模型普通文字中的“我没有工具”作为工具声明缺失证据。

### 3. 交付最小真实对照包，worker 不执行

在 `probe_cases.json` 中用明确占位模型标识、合成内容和相同工具 schema 准备基准；不填真实 Key、地址、模型配置或既有会话数据。独立基准必须依据官方规则手工确定，不能调用 Mica 编码器生成期望值后再与其自身比较。

在汇报中说明后续由用户参与、经边界确认后进行的分阶段实验：

1. 全新 Messages 历史、关闭思考、一个只读工具，对照独立协议最小请求与 Mica 实际请求；对齐模型、工具 schema、任务和相关参数，列明系统指引等剩余差异，不因两侧结果不同就直接判定 Mica 有 bug。
2. 先测自动工具选择；仅当未产生调用且协议/模型支持相应选项时，再在诊断请求中明确指定工具。强制选择只用于定位，不改变产品默认策略。每次只改一个变量，列明每个用例的停止条件、请求预算和信息增益，不做盲目重试。
3. 新会话工具往返明确后，再比较原生 Messages 工具历史与 Completions 转换历史。优先离线比较现有编码的 id、参数对象、角色、content block 和 tool_result 顺序；真实历史只能由后续新建隔离实验产生，不读取用户现有会话，不从模型普通文本伪造成功的工具事实。
4. 真实观察清单至少包含：实际出站字段结构、HTTP 状态、是否出现 tool_use、是否解析成工具事件、是否执行唯一获准 read、是否带结果续问、是否正常结束。只记录白名单摘要；不持久化原始真实请求/响应、凭据、地址或本地绝对路径。

### 4. 给出可裁决的发现

- 每项发现分别标为：静态核对、离线复现、历史真实证据或待真实验证；附准确源码/测试位置与最小复现。
- 区分请求编码差异、流解析/Engine 交接问题、工具选择行为及渠道兼容性假设；不能由模拟响应得出真实模型支持或不支持的结论。
- 若发现产品缺陷，说明输入 → 实际结果 → 预期结果、建议修改的模块和必要回归范围；不在本卡实现修复。
- 若没有确认缺陷，交付最小对照包、已排除的本地断点、仍缺少的证据及下一步。不得为了“定位完成”强行归因。
