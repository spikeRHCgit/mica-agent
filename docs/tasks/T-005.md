## 候选经验

<!-- 可复用的教训：现象、证据位置、建议去向 -->

- **精确字节资源需要显式 checkout 契约**：当测试要求包资源不含 CR 时，只依赖仓库 blob 为 LF 不足以
  保证 Windows 工作树字节一致；`core.autocrlf=true` 会在 Git 状态 clean 的同时生成 CRLF。应由 master
  评估用 `.gitattributes` 对该类资源声明 `text eol=lf`，并在独立任务中验证分发和 Windows checkout。
- **全量失败不盲目重跑**：本次一次性全量验证失败后，通过 blob、raw worktree bytes、attributes 和 Git
  config 定位到范围外环境差异；没有用重跑、放宽断言或越界修改掩盖失败。
