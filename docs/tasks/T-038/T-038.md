## 实现目标

1. 三个内置渠道有固定目录表和独立解析：DeepSeek、OpenRouter、OpenCode Go。空列表、请求/结构失败、需要手填有明确不同结果；目录成功不冒充 Key 认证成功、账号可推理或额度可用。
2. 返回模型 ID、展示名和能明确对应现有配置的能力；未知能力保持未知，不把默认值写成远端发现，不按名称/价格/接口名猜 reasoning 或上下文。Go 新模型接口未知必须显式选择，不能自动全设 Completions。
3. 只保存用户选中的模型；刷新仅补缺失字段，保留已有手工字段、未知字段与远端本次未返回但仍被选中的模型。显式取消选择可移除该模型，不把远端暂缺当作用户取消选择。
4. 目录网络等待期间不持有存储锁；取消、超时、断流、无效响应和资源异常有安全结果及确定收口。迟到/过期结果保存用 T-037 目标记录比较，连接已删除或被修改时拒绝，不创建替代连接、不改默认或会话。

## 最小内部接口与状态归属

在 model_catalog.py 内定义不可变的 CatalogTarget、CatalogModel、CatalogResult 等最小数据值，不导出到包顶层。含 Key/URL 的目标必须 repr 隐藏，结果不保留整个原始响应。模型元数据仅使用既有配置字段的白名单，未发现的字段不生成伪“发现来源”。

至少提供等价入口（具体内部辅助可自行选择）：

```python
async def discover(target: CatalogTarget, token: CancellationToken, *,
                   transport: httpx.AsyncBaseTransport | None = None) -> CatalogResult: ...

def save_selection(store: ConfigStore, provider_id: str,
                   expected_provider: Mapping[str, object],
                   catalog: CatalogResult, selected_ids: Collection[str], *,
                   api_choices: Mapping[str, str] | None = None) -> None: ...
```

- target 由调用方显式传入 channel、已确认的连接信息与必要 Key，不读取真实配置、环境 Key、auth 或其他客户端数据。自定义目录 URL 为可选运行期输入，不新增持久化字段；未提供时明确返回需要手填。
- discover 每次拥有其 HTTPX client/响应以及取消观察任务，finally 中全部收口。注入 transport 只用于网络边界测试，所有权明确交给这次 client；不 fake 解析、合并或存储业务。
- 沿用 CancellationToken 的 CancellationRequested 语义；直接 task.cancel 的 CancelledError 也传播，不转为普通请求失败。不让取消后后台请求、任务或响应继续存活。目录不是 Agent Run，不发送 Agent 事件或工具调用。
- save_selection 的 expected_provider 必须为调用前读到的完整已有记录，禁止 None 创建路径。保存仅以 ConfigStore.update_provider 更新 models 字段，默认/凭据/其他供应商不变。可用纯函数先生成合并结果，但不要新增通用事务/缓存框架。

## 目录请求与解析

- 请求表依 channel，而非把三个渠道当成同一协议目录。使用 channel-reference.md 中的固定 URL；DeepSeek/OpenRouter 只向已核实的固定目录发送 Bearer Key，目标的渠道/基址不匹配时请求前拒绝，不借渠道名把任意连接 Key 发给别的目标。
- Go 使用官方公开目录，不发送用户 Key；User-Agent 为 Mica 自有标识。会话头仅接受调用方提供的稳定、无路径/控制字符的会话 ID，不冒充其他客户端、不新建身份持久化格式。目录结果不含逐模型 API，需显式 api_choices 才能保存新模型；已有记录的显式/继承接口事实不因刷新被改写。
- 自定义仅在调用方明确提供同源目录 URL 时尝试；使用目标显式接口对应的认证约定，仅接受 OpenAI 风格 data/id 最小目录结构，其他格式安全失败后允许手填，不假装支持所有自定义渠道。URL 无 userinfo/query/fragment，与显式基址协议/主机/有效端口一致，不尝试路径变体或跨源回退。
- 每次发现最多 **1 次 GET**，总 deadline **30 秒**覆盖建连和流消费，**零自动重试、不跟随重定向**。OpenRouter 不传 offset/limit 以请求规范的完整文本模型目录；next 非空时标结果不完整，不跟随任意地址，也不伪装为完整清单。
- 解压后累计最多 **16 MiB**、条目最多 **10000**；坏 JSON、重复 ID、类型错误或无有效 ID 不能误报为空目录。列表确为空才返回空；合法条目中的未知能力字段可忽略，明确字段类型/值无效则不写为已发现能力，并提供固定安全状态或计数。
- 所有字段经既有配置规则兼容验证：ID/名称可展示，预算为正整数而非 bool；null 表示未提供；输入模态只映射既有支持项；能力组合不能成功写出既有服务无法使用的记录。reasoning/effort 仅从明确声明映射，不能从 supported_parameters 推出所有取值均受支持，不新增思考语义。
- HTTP 认证拒绝、限流、其他 HTTP、网络、超时、过大/坏数据用固定错误类别，不包含 Key、URL、本地路径、原始响应或任意远端错误正文；不因失败清空目录或删除连接。

## 合并与保存

- 同一 ID 保留已有字段（包括手填上下文、maxTokens、名称、API、未知扩展），仅用远端补不存在的字段；新增条目从远端白名单构造，不能把整个响应字典存入配置。
- selected_ids 来自明确选择集，刷新初始选择由已有模型 ID 派生。已选的既有模型即使本次没返回仍保留；新增未选条目不保存；用户显式取消选中的旧模型可以移除。未知且不在当前目录/已有模型中的选中 ID 拒绝，不伪造条目。
- 新 Go/其他未知 API 条目若无显式有效 api_choices 则保存前拒绝，不借 Provider 默认值猜协议；既有明确配置不被远端覆盖。仅支持现有三类接口，不新增 Google 适配。
- failed/manual-required 的结果不能当作成功目录覆盖；不完整结果允许明确选择当前已见项，但不删除仍选中的本地旧项。空目录不自动触发清空保存。
- 更新前比较完整 expected_provider；模拟发现期间并发编辑/禁用/删除后，保存必须冲突且旧字节不变，不绕过比较或把 missing 当作新建。模型列表的任何校验失败均不得部分保存。
