- Ask：default/solo 下正常和空答案都生成真实 TOOL 结果；structured Ask 的 schema、选项、答案、
  Provider 后续上下文、JSONL 持久化、continue 和 Provider close 次数均保留。
- 权限与工具：普通 write/edit/Bash 执行、受保护写入的 allow/deny、非 ASCII 和未知输入重询、

- 失败：副作用发生后 Provider 失败，不提交成功 turn，并明确提醒用户检查工作区。
- 取消：consumer `aclose()`、外部 `task.cancel()`、交互 EOF 和 KeyboardInterrupt 分别保留；
  Permission 与 Ask 等待分支、broker 清理、无后台 task、未授权 handler 不启动、Provider 单次关闭
  及无成功 turn 的断言不得合并丢失。
- Bash 输出：清洗后的 delta 在 started/success 之间；未结束行恰好补一次分隔；无输出时不增加空行；
  stdout/stderr 分工、上下文及会话不保存原始 delta 的断言保持原样。
- 真实文件与 Bash 用例继续使用各测试自己的 pytest 临时目录，不依赖用户工作区或真实会话。
