# Master 项目实践手册

本文记录 master 在本项目中已经提炼、仍然有效的实践，在本项目内优先于角色卡的默认做法。

- **任务分支**：使用任务分支时，分支名 `task/T-###-<英文短名>`，worktree 放在 `../mica-wt/T-###`；卡片提醒 worker 在新 worktree 先执行 `uv sync --python 3.11`，会话数据根用独立临时目录。共享契约、依赖配置和热点文件的卡按顺序派，不并行。
- **契约任务**：公共输出和 wire 变更，卡片的完成标准里写直接断言和安装态验证；设计审查和兼容要求引用 `docs/code_spec.md` §1.3、§2.4。
- **视觉验收**：视觉任务在卡片中指明相关的正向、负向参考图，对照流程按 `docs/assets/tui/README.md`；自动化截图不能替代用户真实终端确认。
