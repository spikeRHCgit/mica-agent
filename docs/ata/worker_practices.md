# Worker 项目实践手册

本文记录 worker 在当前项目中已经提炼并仍然有效的实践，作为worker必须时刻遵循以下指导。

- **异步等待**：异步或进程测试优先等待可观察事件并设置有余量的超时；仅在必须证明延迟副作用未发生时使用必要的墙钟等待。
- **测试归位**：新测试优先放在最接近行为边界的现有文件；只有独立契约或测试装配确有需要时才新建文件。
- **分层验证**：先完成可运行的功能闭环，再用代表性公共场景做聚焦验证；稳定后按任务风险完成兼容、全量和构建检查，不机械重复运行。
- **间歇失败**：遇到间歇失败先保留诊断证据并定位原因；只有发现不稳定性证据时才安排重复运行。
- **视觉对照**：视觉任务要实际查看正向参考图和问题图，在相同状态与可比视口下提供对照证据，并明确真实终端验收仍由用户确认。
- **报告聚焦**：交付报告聚焦最终实现、实际问题、验证结果与剩余风险，不记录逐条命令流水。
