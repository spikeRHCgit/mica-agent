# Worker 项目实践手册

本文记录 worker 在当前项目中已经提炼并仍然有效的实践，作为worker必须时刻遵循以下指导。代码、测试与验证规则见 `docs/code_spec.md`，不在本文重复。

- **任务卡交接**：以任务卡 `docs/tasks/<ID>.md` 为任务边界；每个里程碑、会话结束或上下文压缩前在「进展与交接」追加 1～3 行，候选经验写入任务卡的「候选经验」，不写入 `docs/ata/notes/`。
- **视觉对照**：视觉任务要实际查看任务卡指定的正向参考图和问题图，按 `docs/assets/tui/README.md`「使用规则」提供对照证据，并明确真实终端验收仍由用户确认。
- **报告聚焦**：交付报告聚焦最终实现、实际问题、验证结果与剩余风险，不记录逐条命令流水。
